一周家庭健身计划 - iPhone 离线 PWA（家庭成员版）

新增功能：
- 家庭成员选择：妈妈 / 爸爸 / 女儿
- 妈妈：保留原一周训练计划
- 爸爸：完整周一到周日 10–15 分钟站立为主训练，核心 + 增肌 + 轻有氧；语音强调发力呼气、避免憋气
- 女儿（14岁）：每天相同的肩颈与脊柱训练
  1. 筋膜球放松肩胛骨周围与胸小肌
  2. 猫牛式 12次 × 2组
  3. 轻阻力肩关节外旋 10次 × 2组
  4. 轻阻力弹力带颈后抗阻 12次 × 3组：弹力带置于后脑勺/枕骨后方，配合呼吸，每次保持2–3秒
- 女儿训练包含中文语音提示：开始、节奏、换边/换方向、休息与完成
- 每个家庭成员分别保存完成记录
- 可关闭语音提醒
- PWA 离线缓存

iPhone 安装：
1. 将全部文件上传到同一个 HTTPS 静态网站目录。
2. 用 iPhone Safari 打开网站。
3. 分享 -> 添加到主屏幕 -> 作为 Web App 打开。
4. 完整打开一次后，核心页面可离线使用。

注意：
- 语音使用 iPhone / Safari 提供的系统语音合成功能。离线是否能发声取决于设备上是否已有可离线使用的中文系统语音。
- 完成记录保存在当前设备的 Web App 本地存储中。
- 删除 Web App 或清理 Safari 网站数据可能清除记录。
- 女儿的颈部训练采用最轻阻力弹力带置于后脑勺/枕骨后方，颈部保持中立；弹力带不要绕过颈前或颈侧。出现头晕、头痛、麻木、锐痛或症状加重时应停止。

- 爸爸：主要动作已加入示范/视频链接入口（链接需联网打开，训练计划本身仍可离线使用）

- 妈妈：主要动作已加入示范/视频链接入口（链接需联网打开，训练计划本身仍可离线使用）
