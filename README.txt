家庭健身 PWA - 可展开动作说明版

新增：
- 每个训练动作卡片都可展开“动作说明”
- 展开后直接显示：
  1. 动作要点
  2. 常见错误
  3. 呼吸节奏
  4. 初学者替代动作
- 保留语音动作要领
- 保留完整详细解说页
- 详细页继续提供图片搜索与视频演示入口
- 保留训练正计时、当前动作时长、自动滚动、训练进度、独立完成记录
- 保留 Screen Wake Lock 常亮支持
- 核心页面支持 PWA 离线缓存

部署：
将 index.html、manifest.webmanifest、sw.js 和两个 icon 文件上传到 GitHub Pages 同一目录。

- 动作切换语音流程：
  1. 先播报“下一个动作 + 动作名称 + 每组次数/时长 + 组数”
  2. 播报结束后才开始该动作计时
  3. 计时开始后同步朗读动作要点和呼吸节奏
  4. 2分钟后继续按每1分钟进行时长语音提醒

本版新增：
- 女儿筋膜球放松：仅左右肩胛骨周围，各60秒
- 女儿猫牛式：12次/组 × 2组

- 中文语音优先选择系统中的女性声音；若设备没有可用女声则回退到可用中文语音

- 暂停后继续训练时，仅播报“继续训练”，不重复次数、组数、动作要点或呼吸提示。
